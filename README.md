# Standpipe Monitoring — Nui Phao

Static dashboard for groundwater and shared daily rainfall monitoring at the Nui Phao mine.

## Open the dashboard

After GitHub Pages is enabled, the main page is:

https://doancongbien96-beep.github.io/Standpipe_monitoring_Nuiphao/

Direct dashboard page:

https://doancongbien96-beep.github.io/Standpipe_monitoring_Nuiphao/standpipe-monitoring.html

## Publish

The included GitHub Actions workflow publishes the repository root whenever changes are pushed to the main branch. In the repository settings, enable Settings → Pages → Build and deployment → GitHub Actions if Pages is not enabled yet.

## Data and privacy

The dashboard runs in the browser. Data entered or imported into it is saved in that browser's local storage, and imported location images are saved in that browser's local IndexedDB. They are not automatically shared with other users or devices. Use the dashboard's backup/export features to transfer records.

The location map and rainfall CSV template are included in this repository.
